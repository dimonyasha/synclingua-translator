# SyncLingua Translator 🎙️🌍

**SyncLingua** — это расширение для Chrome и локальный Python-сервер для синхронного перевода аудио в реальном времени. Оно захватывает звук активной вкладки (YouTube, Twitch, онлайн-курсы), распознает речь, переводит её и озвучивает на русском языке с минимальной задержкой.

В отличие от облачных аналогов (например, DubTab), **SyncLingua работает полностью локально**. Ваш звук не отправляется на сторонние серверы, а все нейросети (распознавание, перевод и синтез речи) работают на вашем компьютере.

## ✨ Основные возможности

*   **Синхронный перевод:** EN → RU.
*   **Субтитры:** Отображение текста прямо поверх видео (с настройкой размера шрифта).
*   **Ducking (приглушение):** Оригинальный звук автоматически затихает, когда говорит переводчик.
*   **Выбор голоса:** Три локальных нейроголоса (Dmitri, Irina, Ruslan).
*   **Универсальность:** Работает на YouTube, Twitch, Vimeo и других сайтах.
*   **Конфиденциальность:** 100% локальная работа без API-ключей и подписок.

## 🛠️ Технологический стек

*   **Сервер:** Python, FastAPI, WebSockets.
*   **ASR (Распознавание речи):** Faster-Whisper (модель `base`).
*   **MT (Перевод):** Ollama (модель `qwen2.5:7b`).
*   **TTS (Синтез речи):** Piper TTS (локальные ONNX-модели).
*   **Клиент:** Chrome Extension (Manifest V3), AudioWorklet API.

## 🚀 Установка и запуск

### Предварительные требования

1.  **Python 3.10+** (установлен и добавлен в PATH).
2.  **Ollama** (скачать с [ollama.com](https://ollama.com/)).
3.  **Google Chrome** (версия 116+).
4.  Желательно наличие видеокарты (NVIDIA) для быстрой работы Whisper, но можно и на CPU.

### Часть 1: Настройка Сервера

1.  Скачайте модель для перевода через Ollama (откройте обычную командную строку):
    ```bash
    ollama run qwen2.5:7b
    ```
    *(Дождитесь загрузки ~4.7 ГБ. После появления чата можно написать `/bye`).*

2.  Перейдите в папку с сервером (где лежит `server.py`):
    ```bash
    cd путь_к_папке/audio_translator
    ```

3.  Создайте виртуальное окружение и установите зависимости:
    ```bash
    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    ```
    *(Если файла `requirements.txt` нет, установите вручную:)*
    ```bash
    pip install fastapi uvicorn faster-whisper ollama argostranslate piper-tts requests huggingface_hub
    ```

4.  Запустите сервер:
    ```bash
    python server.py
    ```
    *При первом запуске сервер скачает модели Whisper и Piper (~150-200 МБ). Дождитесь сообщения **Сервер готов**.*

### Часть 2: Установка Расширения

1.  Откройте Chrome и перейдите по адресу: `chrome://extensions/`
2.  Включите **«Режим разработчика»** (переключатель в правом верхнем углу).
3.  Нажмите кнопку **«Загрузить распакованное расширение»**.
4.  Выберите папку `chrome-translator` (где лежат `manifest.json`, `content.js` и др.).
5.  Закрепите иконку **SyncLingua** на панели браузера.

## 🎮 Как пользоваться

1.  Убедитесь, что сервер (`python server.py`) запущен и работает.
2.  Откройте видео на YouTube или Twitch.
3.  Нажмите на иконку **SyncLingua** и нажмите **«Включить перевод»**.
4.  Подождите 3-5 секунд. Вы услышите русскую озвучку и увидите субтитры.

## ⚠️ Известные ограничения

*   **Требовательность к ресурсам:** Для работы Ollama (Qwen 7B) требуется минимум 8 ГБ оперативной памяти (рекомендуется 16 ГБ) и видеокарта для комфортной скорости.
*   **DRM-защита:** Расширение может не работать на стриминговых платформах с жесткой защитой контента (Netflix, Disney+), так как Chrome блокирует захват их звука.
*   **Задержка:** Из-за использования LLM (Ollama) задержка перевода может составлять 1.5–3 секунды. Это плата за высокое качество перевода.
