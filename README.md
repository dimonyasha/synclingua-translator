SyncLingua — это расширение для Chrome и локальный сервер, которые переводят английскую речь в видео на русский язык в реальном времени. 
В отличие от облачных сервисов, **ваш звук не покидает ваш компьютер**. Распознавание, перевод и синтез речи происходят локально на вашем ПК.

## ✨ Основные возможности
*   **Синхронный перевод:** EN → RU в реальном времени.
*   **Локальность:** Полная приватность, никаких подписок и отправки данных на сторонние серверы.
*   **Озвучка:** 4 качественных голоса на выбор (3 мужских, 1 женский).
*   **Субтитры:** Отображение текста поверх видео с настройкой размера.
*   **Умное приглушение:** Оригинальный звук автоматически затихает, когда говорит переводчик (Ducking).
*   **Гибкость:** Настройка громкости перевода и оригинала, а также задержки перевода.

## 🚀 Установка и запуск (Для пользователей)

### Шаг 1: Установите Ollama и модель
1. Скачайте и установите [Ollama](https://ollama.com/download).
2. Откройте командную строку (`cmd`) и выполните:
   ```cmd
   ollama pull translategemma:4b
(Дождитесь окончания загрузки, модель весит около 3.3 ГБ).

Шаг 2: Установите SyncLingua
Перейдите в раздел Releases на этой странице.

Скачайте файл SyncLingua_Setup.exe и запустите его.

Следуйте инструкциям установщика. На рабочем столе появится ярлык «SyncLingua Server». Запустите его.

Дождитесь появления в консоли строки Uvicorn running on http://127.0.0.1:8000. Окно не закрывайте.

Шаг 3: Установите расширение в Chrome
Так как расширение пока не опубликовано в официальном магазине, установим его через «Режим разработчика»:

Откройте браузер Chrome и перейдите по адресу chrome://extensions/.

Включите «Режим разработчика» (тумблер в правом верхнем углу).

Нажмите кнопку «Загрузить распакованное расширение» (в левом верхнем углу).

Перейдите в папку, куда установилась программа (по умолчанию: C:\Program Files\SyncLingua\chrome-translator), и выберите её.

Расширение установлено! Закрепите иконку SyncLingua на панели Chrome.

Шаг 4: Использование
Откройте видео на YouTube, Twitch или другом поддерживаемом сайте.

Нажмите на иконку SyncLingua и нажмите «Включить перевод».

Наслаждайтесь русской озвучкой и субтитрами!

(Если субтитры не появились сразу — обновите страницу с видео (F5)).

## 🌐 Гибридный режим (Локально / Облако)

Начиная с версии 1.1.0 в SyncLingua появился выбор режима перевода:
1. **Локально (Ollama)** — 100% приватно, работает без интернета (после скачивания моделей).
2. **Облако (OpenAI-совместимый API)** — быстро, не грузит ваш ПК. Отлично подходит для слабых ноутбуков.

*В облачном режиме звук по-прежнему распознается локально (Whisper), а в сеть уходит только распознанный текст!*

### Как настроить облако (на примере GigaChat от Сбера):
1. Зайдите на [developers.sber.ru](https://developers.sber.ru), создайте проект GigaChat API (выберите физлицо, чтобы получить бесплатный лимит токенов).
2. Скопируйте **Ключ авторизации** (Authorization key, длинная строка Base64).
3. В настройках расширения выберите режим **«Облако»**.
4. Заполните поля:
   * **URL API:** `https://api.giga.chat/v1`
   * **API Ключ:** ваш Ключ авторизации
   * **Модель:** `GigaChat-2`
5. **Важно:** снимите галочку «Проверять SSL-сертификат» (у Сбера собственные сертификаты, которых нет в Windows по умолчанию).

*(Также вы можете использовать OpenRouter, Groq или любой другой OpenAI-совместимый сервис, указав их URL, ключ и модель).*

🛠️ Технологический стек
Server: Python 3.11, FastAPI, WebSockets

ASR: Faster-Whisper (локально)

Translation: Ollama (translategemma:4b)

TTS: Piper TTS (локально)

Client: Chrome Extension (Manifest V3), Web Audio API
