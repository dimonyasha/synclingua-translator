========================================
  SyncLingua Translator — Инструкция (v1.1.0)
========================================

SyncLingua — это расширение для Chrome и локальный сервер, которые
переводят звук вкладки (YouTube, Twitch, Coursera и др.) на русский
язык в реальном времени: с озвучкой и субтитрами.

В версии 1.1.1 появился ГИБРИДНЫЙ РЕЖИМ:
- Локально: 100% приватно, работает на вашем ПК (требуется Ollama).
- Облако: быстро, без нагрузки на ПК (нужен API-ключ, например, GigaChat).


----------------------------------------
 1. ЧТО НУЖНО УСТАНОВИТЬ (один раз)
----------------------------------------

1.1. Google Chrome (версия 116 или новее).

1.2. (Опционально) Ollama — ТОЛЬКО для локального режима.
     Если вы планируете использовать облачный режим (например, GigaChat),
     устанавливать Ollama и скачивать 3 ГБ моделей НЕ НУЖНО.
     
     Для локального режима:
     - Скачайте и установите Ollama: https://ollama.com/download
     - Откройте командную строку (Win + R → cmd) и выполните:
         ollama pull translategemma:4b
     - Дождитесь окончания загрузки (около 3.3 ГБ).


----------------------------------------
 2. ЗАПУСК СЕРВЕРА
----------------------------------------

2.1. Найдите на рабочем столе ярлык "SyncLingua Server" и запустите его.

2.2. ВАЖНО: при первом запуске окно может казаться "зависшим".
     Это нормально — сервер загружает базовые модели (Whisper и Piper).
     Подождите 10–30 секунд, пока не появится строка:

         INFO:     Uvicorn running on http://127.0.0.1:8000

     НЕ ЗАКРЫВАЙТЕ это окно, пока пользуетесь переводом.
     Чтобы остановить сервер — закройте окно или нажмите Ctrl+C.

2.3. Если антивирус спросит разрешение на доступ к сети — разрешите.


----------------------------------------
 3. УСТАНОВКА РАСШИРЕНИЯ В CHROME
----------------------------------------

3.1. Откройте Chrome и перейдите по адресу: chrome://extensions/
3.2. Включите "Режим разработчика" (справа вверху).
3.3. Нажмите "Загрузить распакованное расширение".
3.4. Выберите папку "chrome-translator" (по умолчанию: 
     C:\Program Files\SyncLingua\chrome-translator).
3.5. Закрепите иконку SyncLingua на панели Chrome.


----------------------------------------
 4. НАСТРОЙКА РЕЖИМА ПЕРЕВОДА
----------------------------------------

Откройте окно расширения (иконка SyncLingua) и выберите "Режим перевода":

[Локально]
- Работает без интернета (после скачивания моделей).
- Абсолютная приватность.
- Требует мощного ПК.

[Облако]
- Мгновенный старт, не нагружает ПК.
- В сеть отправляется ТОЛЬКО текст (аудио остается у вас).
- Вам понадобится API-ключ.

--- Пример настройки ОБЛАКА (GigaChat от Сбера) ---
1. Зарегистрируйтесь на developers.sber.ru (выберите физлицо).
2. Получите "Ключ авторизации" (Authorization key).
3. В расширении выберите "Облако" и заполните:
   URL API: https://api.giga.chat/v1
   API Ключ: [Ваш Ключ авторизации]
   Модель: GigaChat-3-Ultra (или GigaChat-2)

4. РЕШЕНИЕ ПРОБЛЕМЫ С SSL-СЕРТИФИКАТОМ:
   У Сбера собственные сертификаты безопасности. 
   Начиная с этой версии, SyncLingua автоматически подхватывает 
   их из установщика. Вам НЕ НУЖНО ничего настраивать, 
   оставьте галочку "Проверять SSL-сертификат" включенной.
   
   (Если у вас всё же возникнет ошибка соединения, 
   снимите галочку в настройках. Но это снижает безопасность).
---------------------------------------------------


----------------------------------------
 5. КАК ПОЛЬЗОВАТЬСЯ
----------------------------------------

5.1. Убедитесь, что сервер запущен.
5.2. Откройте видео на YouTube, Twitch и т.д.
5.3. Нажмите на иконку SyncLingua → "Включить перевод".
5.4. Подождите 3–5 секунд — появится русская озвучка и субтитры.

ВАЖНО: после установки или обновления расширения обязательно
обновите страницу с видео (F5), иначе расширение не подхватится.


----------------------------------------
 6. ВОЗМОЖНЫЕ ПРОБЛЕМЫ
----------------------------------------

- "GigaChat заблокировал фразу" в логах — это встроенная цензура Сбера. 
  Программа просто пропустит эту фразу, чтобы не читать вам лекции.

- "Неверный API-ключ" — проверьте, что вставили именно Ключ авторизации, 
  а не Client Secret.

- Субтитры не появились — обновите страницу (F5).

- Сервер не запускается — если используете локальный режим, проверьте, 
  что Ollama установлена и запущена.


----------------------------------------
 7. ПРИВАТНОСТЬ
----------------------------------------

- В режиме "Локально": аудио и текст не покидают ваш компьютер.
- В режиме "Облако": аудио распознается локально (Whisper), 
  но текст отправляется на указанный вами сервер API.
- Никакие данные не отправляются разработчику SyncLingua.
