========================================
  SyncLingua Translator — Инструкция (v1.1.2)
========================================

SyncLingua — это расширение для браузера и локальный сервер, которые
переводят звук вкладки (YouTube, Twitch, Coursera и др.) на русский
язык в реальном времени: с озвучкой и субтитрами.

В версии 1.1.2 появился ГИБРИДНЫЙ РЕЖИМ и РЕЖИМ "ТОЛЬКО СУБТИТРЫ":
- Локально: 100% приватно, работает на вашем ПК (требуется Ollama).
- Облако: быстро, без нагрузки на ПК (нужен API-ключ, например, GigaChat).
- Только субтитры: отключает озвучку, экономя ресурсы процессора.


----------------------------------------
 1. ЧТО НУЖНО УСТАНОВИТЬ (один раз)
----------------------------------------

1.1. Браузер Chrome (версия 116+), а также Яндекс.Браузер или Opera.

1.2. (Опционально) Ollama — ТОЛЬКО для локального режима.
     Если вы планируете использовать облачный режим (например, GigaChat),
     устанавливать Ollama и скачивать 3 ГБ моделей НЕ НУЖНО.
     
     Для локального режима:
     - Скачайте и установите Ollama: https://ollama.com/download
     - Откройте командную строку (Win + R → cmd) и выполните:
         ollama pull translategemma:4b
     - Дождитесь окончания загрузки (около 3.3 ГБ).


----------------------------------------
 2. ЗАПУСК СЕРВЕРА
----------------------------------------

2.1. Найдите на рабочем столе ярлык "SyncLingua Server" и запустите его.

2.2. ВАЖНО: при первом запуске окно может казаться "зависшим".
     Это нормально — сервер загружает базовые модели (Whisper и Piper).
     Подождите 10–30 секунд, пока не появится строка:

         INFO:     Uvicorn running on http://127.0.0.1:8000

     НЕ ЗАКРЫВАЙТЕ это окно, пока пользуетесь переводом.

2.3. Если антивирус спросит разрешение на доступ к сети — разрешите.


----------------------------------------
 3. УСТАНОВКА РАСШИРЕНИЯ В БРАУЗЕР
----------------------------------------

3.1. Откройте браузер и перейдите по адресу: chrome://extensions/
     (Для Яндекс.Браузера: browser://extensions/)
3.2. Включите "Режим разработчика" (справа вверху).
3.3. Нажмите "Загрузить распакованное расширение".
3.4. Выберите папку "chrome-translator" (по умолчанию: 
     C:\Program Files\SyncLingua\chrome-translator).
3.5. Закрепите иконку SyncLingua на панели браузера.


----------------------------------------
 4. НАСТРОЙКА РЕЖИМА ПЕРЕВОДА
----------------------------------------

Откройте окно расширения (иконка SyncLingua) и настройте режим:

[Локально]
- 100% приватность (аудио и текст не покидают ПК).
- Требует мощного ПК.

[Облако]
- Не нагружает ПК. В сеть уходит ТОЛЬКО текст.
- Требует API-ключ (GigaChat, OpenRouter и др.).

[Только субтитры]
- Отключает озвучку (Piper TTS).
- Идеально для слабых ноутбуков или если вы хотите просто читать перевод.

--- Пример настройки ОБЛАКА (GigaChat от Сбера) ---
1. Зарегистрируйтесь на developers.sber.ru (выберите физлицо).
2. Получите "Ключ авторизации" (Authorization key).
3. В расширении выберите "Облако" и заполните:
   URL API: https://api.giga.chat/v1
   API Ключ: [Ваш Ключ авторизации]
   Модель: GigaChat-3-Ultra (или GigaChat-2)

4. SSL-СЕРТИФИКАТ:
   У Сбера собственные сертификаты безопасности. 
   Начиная с этой версии, SyncLingua автоматически подхватывает 
   их из установщика. Вам НЕ НУЖНО ничего настраивать, 
   оставьте галочку "Проверять SSL-сертификат" включенной.
---------------------------------------------------


----------------------------------------
 5. КАК ПОЛЬЗОВАТЬСЯ
----------------------------------------

5.1. Убедитесь, что сервер запущен.
5.2. Откройте видео на YouTube, Twitch и т.д.
5.3. Нажмите на иконку SyncLingua → "Включить перевод".
5.4. Подождите 3–5 секунд — появится русская озвучка и/или субтитры.

ВАЖНО: после установки или обновления расширения обязательно
обновите страницу с видео (F5), иначе расширение не подхватится.


----------------------------------------
 6. ВОЗМОЖНЫЕ ПРОБЛЕМЫ
----------------------------------------

- "GigaChat заблокировал фразу" — встроенная защита Сбера. 
  Программа просто пропустит эту фразу.

- "Неверный API-ключ" — проверьте, что вставили именно Ключ авторизации.

- Субтитры не появились — обновите страницу (F5).

- Сервер не запускается — если используете локальный режим, проверьте, 
  что Ollama установлена и запущена.


----------------------------------------
 7. ПРИВАТНОСТЬ
----------------------------------------

- В режиме "Локально": аудио и текст не покидают ваш компьютер.
- В режиме "Облако": аудио распознается локально (Whisper), 
  но текст отправляется на указанный вами сервер API.
- Никакие данные не отправляются разработчику SyncLingua.


----------------------------------------
 8. СИСТЕМНЫЕ ТРЕБОВАНИЯ
----------------------------------------

Требования к оборудованию напрямую зависят от выбранного режима работы приложения:

☁️ Режим «Облако» и «Только субтитры»

Все тяжелые вычисления (распознавание и перевод) выполняются на удаленном сервере.
• Процессор: Любой современный 2-ядерный (Intel Core i3 / Ryzen 3 и выше).
• Оперативная память: 4 ГБ (рекомендуется 8 ГБ для плавной работы ОС).
• Видеокарта: Не требуется (подойдет любая встроенная).
• Накопитель: 1 ГБ свободного места.

💻 Режим «Локально» (Ollama + Whisper + Piper)

Все нейросети запускаются прямо на вашем компьютере. Скорость работы напрямую зависит от мощности видеокарты.
• Процессор:
	• Windows / Linux: 4-ядерный (Intel Core i5 / Ryzen 5 и выше).
	• macOS: Apple Silicon (M1 / M2 / M3 / M4).
• Оперативная память:
	• Минимум: 8 ГБ (запустятся только самые легкие, сильно сжатые модели).
	• Рекомендуется: 16 ГБ и более (для стабильной работы без зависаний).
• Видеокарта (для Windows / Linux):
	• Минимум: NVIDIA с 4 ГБ VRAM (работа будет медленной).
	• Рекомендуется: NVIDIA GeForce RTX 2060 / 3060 и новее с 6+ ГБ VRAM (наличие тензорных ядер критично для комфортной скорости).
	• Для macOS: Отдельная видеокарта не нужна, нейросети задействуют объединенную память процессоров Apple Silicon.
• Накопитель: 10 ГБ свободного места. Настоятельно рекомендуется SSD — на обычном HDD модели будут загружаться в память несколько минут.
⚠️ Примечание: Локальный режим может работать и вообще без видеокарты (только на процессоре), но в этом случае задержка распознавания и перевода будет заметно выше.
